# YouTube Musicへの曲リスト追加

提供された曲とURLを使い、指定の再生リストへ追加する。曲の同定、保存操作、保存先での確認を分けて記録する。

## 実行環境

- Luna Highでの利用を想定した、1担当で順番に操作する手順。呼び出す前にユーザーがモデルと推論設定を選ぶ。このスキルは設定を変更せず、別モデルへの自動委任もしない。
- 内蔵ブラウザは `mcp__cua_repl` を使い、初期化と操作はそのツールの最新説明に従う。指定されたタブを優先し、タブやログイン先が複数なら対象を確認する。
- ブラウザの操作は1担当に限定する。非公開API、Cookie抽出、別のブラウザ自動化へ迂回しない。

## 準備

1. チャットまたは指定ファイルから `番号・曲名・アーティスト・URL・指定版` を抽出する。URLなしの曲は曲名とアーティストからYouTube Music内で検索する。参照履歴に一覧がない場合だけ、一覧の提供を求める。
2. 指定プレイリストの名前とURL/IDを画面で確認し、既存の曲IDを取得する。同名プレイリストが複数ある場合は保存先を確定する。作成が依頼されている場合は指定の公開範囲で作成し、指定なしなら非公開にする。
3. `work/youtube-music-progress.json` に保存先と進捗を保持する。複数の作業がある場合は区別できるファイル名にする。再開時は既存の進捗とプレイリストの現在状態を照合する。

進捗の各項目は `番号、指定曲名、指定アーティスト、元URL、選択タイトル、選択アーティスト、選択版、videoId、状態、確認根拠、保留理由` を持つ。状態は `未処理 / 保留 / 保存操作済み / 登録確認済み / 既存 / 状態不明`。候補を見つけただけでは保存済みにしない。

## 1曲ずつ行う操作

1. **提供URLをそのまま開く。** `watch?v=...` は曲ページ、`search?q=...` は検索結果。検索URLは保存対象そのものではないため、結果から指定曲を選ぶ。プレイリストやアルバムのURLを、1曲のURLとして扱わない。
2. タイトルとアーティストを照合する。表記ゆれや同一人物の英語名は許容し、アルバム・版・時間など表示された情報を補助にする。原曲の公式音源を優先する。指定版がある場合はその版に一致させる。
3. **同名でも別アーティスト、似た別曲、カバー、歌あり版への置換は保留する。** ライブ版や編曲版しかない場合も、許可がなければ候補として記録する。指定アーティストが演奏者でなく作曲者なら、作品・曲・録音情報で同定し、不明なら保留する。分割音源は勝手に複数曲へ展開しない。明確な曲の処理は続け、保留項目をまとめて提示する。
4. 選択曲の `videoId` を画面上のリンクから取得し、保存先の既存ID・今回の追加IDと照合する。既にあれば追加せず `既存` にする。IDを取得できない場合は、表示情報で照合してその限界を記録する。同一録音の重複が疑わしければ確認する。
5. **選択した曲の行または曲ページのメニュー**から「再生リストに保存」を開き、確定した保存先を選ぶ。検索ページ全体・アルバム全体のメニューと取り違えない。保存完了の表示を確認して `保存操作済み` とし、進捗を更新する。
6. タイムアウトや通信エラーで保存結果が不明なら `状態不明` にする。保存先を確認してから再試行する。確認できない間は二重追加を避け、対象曲を保留する。

## 観測量と再開

- 通常は対象の曲名・アーティスト・版・曲URL、操作メニュー、保存先、完了表示だけを取得する。ページ全文や全検索結果を毎回出力しない。
- 実際の画面で確認した操作は、小さな再利用ヘルパーにまとめてよい。画面の遷移と追加は直列に行い、曲ごとの照合と保存結果確認を省略しない。画面構造が変わったら再観測する。
- 保存結果を曲ごとに記録し、数曲ずつ保存先で照合する。再開時は `保存操作済み` と `状態不明` を先に照合してから、未処理項目を進める。

## 完了確認と報告

保存先を開き直し、読み込み・スクロールを含めて必要な曲URLを取得する。表示されている範囲だけを全曲とみなさない。新規追加IDと既存IDを照合し、実際に存在する項目を `登録確認済み` または `既存` にする。総曲数だけで各曲の登録を断定しない。全体を取得できない場合は確認できた範囲を明記する。

報告は `対象項目数、新規追加を確認できた数、既存の数、未確認の数、保留の数、再生リストへのリンク` を示す。対象の番号と保存先のIDを対応させ、曲数と分割音源のトラック数を区別する。保留項目には理由と候補を添える。追加ログだけで完了を宣言せず、途中終了でも進捗ファイルから再開できるようにする。
